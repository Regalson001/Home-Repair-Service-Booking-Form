## 📖 Overview

Finding and requesting reliable home repair services should be simple. Fixora demonstrates how a structured booking form can help customers provide their contact details, select a service, describe a repair issue, and indicate their preferred appointment time.

This project focuses on clean interface design, semantic HTML, responsive CSS, and a straightforward user experience.

## ✨ Features

- **Customer Information:** Fields for customer contact details.
- **Service Selection:** Options for plumbing, electrical repairs, painting, and other home maintenance services.
- **Property Details:** Inputs for property type and location.
- **Appointment Scheduling:** Fields for preferred service date and time.
- **Urgency Selection:** Allows customers to indicate how urgently a repair is needed.
- **Repair Description:** A dedicated field for explaining the issue.
- **Form Validation:** Uses supported native HTML validation rules for required fields and valid input formats.
- **Responsive Layout:** Designed to adapt to desktop, tablet, and mobile screen sizes.
- **Clean User Interface:** Modern styling with clear sections, readable text, and accessible form labels.

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### Prerequisites

You need:

- A modern web browser, such as Chrome, Firefox, or Edge.
- Git installed on your computer.
- A code editor such as Visual Studio Code (recommended).

### 1. Clone the Repository

Open your terminal or command prompt and run:

```bash
git clone https://github.com/Regalson001/Home-Repair-Service-Booking-Form.git
```

### 2. Navigate to the Project Folder

```bash
cd Home-Repair-Service-Booking-Form
```

### 3. Open the Project

If you use Visual Studio Code, run:

```bash
code .
```

Alternatively, open the project folder directly in your preferred code editor.

### 4. Run the Website

Open `index.html` in your web browser.

For a convenient development experience, you can also use the **Live Server** extension in Visual Studio Code.

No package installation or build process is required.

## 📝 How to Use

1. Open the Fixora booking form in your browser.
2. Enter your name and contact information.
3. Choose the home repair service you need.
4. Provide your property type and location.
5. Select your preferred appointment date and time.
6. Indicate the urgency of the repair.
7. Describe the repair issue in the description field.
8. Review your information and submit the form.

**Note:** This is a front-end demonstration. Submitting the form does not currently save a booking or send information to a service provider.

## ✅ Validation and Limitations

The form can use built-in browser validation to check required fields and supported input formats before submission.

Current limitations:

- No backend or database is connected.
- Booking requests are not stored or sent to a service provider.
- No user authentication or customer account system is implemented.
- Appointment availability is not verified.
- Server-side validation and automated confirmation messages are not implemented.

These features could be added in a future version.
